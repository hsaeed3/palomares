# AC conventions used, and how each was verified

| Convention | Used as | Verified against |
|---|---|---|
| kn5 binary layout (v5: header, textures, materials, node tree, 44-byte vertices, u16 indices) | `scripts/p2/kn5.py` | moppius/blender-assetto-corsa-tools exporter source (read, not vendored); our reader round-trips every file to the last byte |
| Axis mapping (east, north, up) → AC (x, y=up, z=−north); triangle order kept; UV v flipped | kn5.py `ac_from_local` | same exporter (`convert_vector3`, `uv = (u, −v)`) |
| Embedded PNG textures | 22_build_kn5.py | exporter embeds PNG when the source isn't DDS |
| Physics by name prefix `1ROAD`, `1GRASS`, `1KERB`, `1WALL` + `surfaces.ini` KEYs | build + data/surfaces.ini | common community practice; **not** checked in-game |
| `models_<layout>.ini` `[MODEL_n] FILE/POSITION/ROTATION` multi-layout folder, `ui/<layout>/ui_track.json` | 22_build_kn5.py | community docs; **not** checked against a downloaded track |
| Spawn locators: Y up, **+Z forward** (row 3 of row-major matrix) | `locator()` in 22_build_kn5.py | AcTools ReadMatrix, moppius exporter, stock Barber AC_START_0 vs AI line (see "Spawn / locator orientation") |
| A-B timing `AC_AB_START_L/R`, `AC_AB_FINISH_L/R` | timing kn5 | CLAUDE.md spec; vanilla support unverified |
| Shaders `ksPerPixel`, `ksPerPixelMultiMap` (road), `ksPerPixelAT` (foliage) | materials | standard Kunos shader names; property sets not checked in-game |

## CSP / Pure (Custom Shaders Patch) track config

- CSP reads per-track settings from `content/tracks/<track>/extension/ext_config.ini` when the
  acc-extension-config repo has no config for the track (`extension/config/tracks/<track>.ini` is the
  global/repo location). Vanilla AC ignores the folder. Source: CUP RainFX docs
  https://cup.acstuff.club/docs/csp/tracks/rainfx
- Foliage: CSP/Pure foliage treatment (translucency, tree wind, tree shading) keys on the Kunos
  `ksTree` shader; community configs switch tree materials with
  `[SHADER_REPLACEMENT_n] MATERIALS=... SHADER=ksTree CULL_MODE=DOUBLESIDED` (ks_nordschleife.ini in
  https://github.com/ac-custom-shaders-patch/acc-extension-config/tree/master/config/tracks).
  `PROP_n = name, value` overrides material values; replacements are applied once at load.
  Source: https://cup.acstuff.club/docs/csp/general/shader-replacements ,
  https://github.com/ac-custom-shaders-patch/acc-extension-config/wiki/Tracks-%E2%80%93-Miscellaneous-options
- `[GRASS_FX]` GRASS_MATERIALS / OCCLUDING_MATERIALS / MASK_BLUR / SHAPE_*; `[RAIN_FX]`
  PUDDLES_/SOAKING_/SMOOTH_/ROUGH_/LINES_MATERIALS (main asphalt in both puddles and soaking);
  `[WIND] DYNAMIC_FLAGS=AUTO`; `[LIGHTING] SPECULAR_MULT/LIT_MULT` — key names copied from
  ks_highlands.ini / ks_nordschleife.ini in acc-extension-config.
- Our kn5 v5 with plain ksPerPixel / ksPerPixelMultiMap / ksPerPixelAT needs no format change for CSP.
- Generated by `scripts/p2/ext_config.py`, called at the end of `22_build_kn5.py` (which wipes the
  track folder); it asserts every material it names exists in MATS.

## Spawn / locator orientation (verified against source code and stock-track data)

**Convention:** a kn5 node matrix is 16 little-endian floats, row-major in the row-vector (DirectX/SharpDX) form: floats 0-2 = local X axis, 4-6 = local Y (up), 8-10 = local Z, 12-14 = translation, 15 = 1. For AC_START_n / AC_PIT_n / AC_HOTLAP_START_n the car faces the dummy's **local +Z** (floats 8-10), with local +X on the car's left (X = Y x Z, a proper right-handed rotation).

Sources:
- AcTools (Content Manager) reads the 64 bytes in order into M11..M44 and takes translation from M41..M43: https://github.com/gro-ove/actools/blob/master/AcTools/ReadAheadBinaryReader.cs (`ReadMatrix`), `AcTools/Kn5File/Kn5Basic.cs`, and `AcTools.Render/Kn5SpecificSpecial/TrackMapRenderer.cs` (`MoveCameraToStart`, AC_START_0 translation).
- moppius/blender-assetto-corsa-tools writes `matrix[col][row]`, i.e. the transpose of Blender's column-vector matrix, with axes converted (x, y, z) -> (x, z, -y): https://github.com/moppius/blender-assetto-corsa-tools/blob/master/exporter/kn5_writer.py (`write_matrix`) and `exporter/exporter_utils.py` (`convert_matrix`, `convert_vector3`). Our `ac_from_local` (E, N, U) -> (E, U, -N) is the same mapping.
- AC-evo converter, measured on Kunos stock tracks: "Spawn dummies point along their local +Z: on Barber AC_START_0's +Z is (0.704, 0, -0.710), the AI line's first step (0.70, -0.70)". It reads position from floats 12-14 and forward from floats 8-10. Stock AC1 cars also have their front at +Z and left at +X (ks_mazda_miata WHEEL_LF at (0.705, 0.285, 1.168)): https://github.com/WhoaThatCombo/AC-evo-content-manager- (`converter/docs/FORMATS.md`, `converter/src/track/scan.rs` `Dummy::forward`).
- AC sets the initial heading from these dummies alone. The layouts ship no ai/fast_lane.ai or spawn ini that could override it.
